# Blazor Utility Collection
  
A growing set of lightweight, browser‑based utilities built with Blazor.  
This experimental project focuses on simple, fast, easy‑to‑use tools.  
  
Currently available:  
- Calculator
- Unit Converter
- Counter
- Weather
  
## Getting Started
Clone the repository and navigate into the project folder:

```bash
git clone <repo-url>
cd BlazorUtilityCollection
```
  
## Run the Application
Start the project:
```bash
dotnet run
```
  
## Usage
Follow the instructions displayed in the terminal to open the app in your browser.
